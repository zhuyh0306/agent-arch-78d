## 精读笔记（3 条，能复述才算）

1. **五要素不是清单，是五个失配面；缺哪个，坏法可预测**
   - 角色缺 → 定位漂移；边界缺 → 越权或接不该接的活；输出格式缺 → 下游解析接不住；拒答缺 → 没依据时硬编；引用缺 → 错误无法回溯。
   - 实测：抽象写全五要素的 v1 在 0.5B 上输出「结论：无」，既没拒也没答。**规则写得全 ≠ 模型执行得了**，所以 v1 最终落成「5 条规则 + 3 个例子」，而不是一段描述性散文。
   - 落点：`skills/prompts/system_v1.md`。

2. **例子比抽象规则稳，但例子的判别信号必须能在输入里被看见**
   - 信息不足组最初一直编造 `0%`。原因不是例子不够，而是模型把「表字段名」当成了「有数据」。改成「先数上下文里的 `[doc-x]` 数据行，一行都没有就直接拒答」之后，同一模型立刻稳定拒答。
   - 也就是说：**规则要挂在可观测的输入特征上**（有没有 `[doc-x]`），不能挂在语义判断上（「够不够」）。
   - 落点：`system_v1.md` 规则 1 / 例 2。

3. **提示词管形状，不管事实与算术——这次有实测证据**
   - 正常组 v1 三行结构、`[doc-1][doc-2][doc-3]` 引用全部达标，但 `108/3600` 连续算出 `2.8%`（正确 `3.00%`）。
   - 再加一条「百分比先算小数再乘 100」，信息不足组反而退回编造 `0%`，正常组变成 `2.4%`。1.5B 对规则条数敏感，**加规则会挤掉已有规则**，已回退到 461 tokens 版本。
   - 落点：算术与缺数判断要下沉到工具/代码，属于 Harness 层，不是 Prompt 层；这条直接接 Day 8 契约。

## 五层定位：今天的三个问题各在哪层

| 现象 | 定位 | 处理 |
|---|---|---|
| 越权问题没按标准句式拒 | PE（输出格式 / 拒答） | 换 v1 固定句式 + 升级路径 |
| 上下文里根本没有数据行，模型却算出 0% | CE + PE 交界 | 先用 `[doc-x]` 信号让 PE 能判断，再把缺数校验下沉到代码 |

## 与课程文档的偏差（主动讲出来）

1. 课程给的是决策路径与验收目标，没有现成对照脚本；脚本、用例、记录都是今天新写的。
2. 课程默认一个模型跑三组；0.5B 连「结论/依据/不确定项」都稳不住，先把抽象 v1 输出成「结论：无」，再加例子又串味，最后新增 `balanced`（1.5B）才拿到可判定的结果。
3. 课程把「五要素」当写作清单；实测发现**要素齐全不等于可执行**，最终产物是规则 + 例子，不是五个段落。
4. 课程把「正常提问」预期写成「结论 + 引用，结构稳定」；本次结构与引用达标、算术不达标，按两层分别判定，没有合并成一个「通过」。
5. 越权组在 1.5B 上不具区分度：v0 本身就会拒绝，v1 只改善了升级路径与结构。要验证边界规则的真实作用，需要更强模型或更隐蔽的诱导问法。
6. 产物落在 `skills/prompts/` 而不是课程写的 `prompts/`，因为仓库已是五层布局，`skills/` 才是技能资产的归属。

## 三行收尾

- 卡点：0.5B 无法同时守住「三行结构 + 拒答 + 引用」，抽象规则与例子互相挤占；1.5B 能守住形状，但算术不可靠。
- 绕过：把信息不足的判断改成可观测信号（有没有 `[doc-x]` 数据行）；算术不硬修，明确记成提示词天花板，留给工具层。
- 下次：对照用例要加一组「诱导式越权」（先给正当理由再要跨租户数据），否则边界规则等于没测；同时把算术校验做成对照脚本里的确定性断言。

## 已知限制

- 只测了一个模型家族（qwen2.5 0.5B / 1.5B），结论不能外推到云端强模型。
- 三组用例各一条，不是回归集；没有 P95，也没有多轮对话。
- 正常组算术错误是模型能力问题，不是 v1 的结构问题，但对外仍是一条错误答案；上线前必须由工具算数。
- `system_v1` 的 461 tokens 用 tiktoken o200k 估算，对 qwen 分词器只是近似。
- `contrast-record.md` 每次重跑会被覆盖；长期基线要另存带日期的副本。
- 成本数字用 Day 4 的示意单价，不是本机 Ollama 的真实计费（本地为 0）。
