## 下周前置依赖（Day 13 起）

1. **多租户**：第 3 周第一张业务表就带 `tenant_id` + RLS，迁移脚本同时建策略与用例；否则 R9 会变成返工。
2. **指标字典**：20 条指标的定义 / 公式 / 口径陷阱 / 数据源先定，再写取数提示词。
3. **回归集**：至少 20 条金标问题，配合 Day 7 对照与 Day 8 契约 fixture；没有回归集不改 prompt / 契约。
4. **Trace 字段**：`tenant_id`、路由版本、prompt / 契约版本、原始产出、失败码、重试次数、成本，缺一项都不算可复现。
5. **模型**：强模型 key 到位前，所有结论标注本地 0.5B / 1.5B，不外推。
6. **故障与 HITL**：等 Runtime 最小闭环后再做故障注入与审批 UI，不提前造空壳。
